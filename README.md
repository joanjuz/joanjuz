#  About Me

Hi, I'm **Joan Ugalde**, a **Computer Engineer** focused on software development, code modding, automation, tooling, and practical technology solutions.

I enjoy working across different areas of computing, from low-level concepts, embedded systems, and hardware/software integration, to desktop applications, web tools, scripts, and utilities designed to solve real technical problems.

One of my main interests is **software modding**, especially tools related to game randomization, custom workflows, and code modification. I like understanding how existing systems work internally, improving them, extending their behavior, and building tools that make complex processes easier to use.

I'm highly interested in technology in general, especially areas such as **software engineering**, **automation**, **GNU/Linux**, **systems programming**, **game modding**, **randomizers**, **embedded systems**, and **technical problem solving**.

I consider myself **self-taught**, adaptable, and always willing to learn new tools, languages, and technologies. Whether I'm modifying an existing codebase, building a utility from scratch, or experimenting with hardware/software projects, I enjoy the process of learning how things work and making them better.
